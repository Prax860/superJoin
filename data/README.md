# Sample data

Two folders of public source documents used to demo cross-document comparison:

- `delhivery/` - prospectus, FY24 annual report and Q4 FY24 earnings presentation excerpts
- `india-macroeconomy/` - Economic Survey, RBI Annual Report and IMF Article IV excerpts

Upload two PDFs from the *same* folder to see corroborations, contradictions and
reconciliations. Each folder has its own README describing the sources.
